# UBian-LRC
We are students from IE3A wants you to try ou our working library website to enhance student's and faculty ease while working.
The website contains several functions for students and faculties seperately

NOTE: The students and admin have the same log in interface

The following are features for the students:
- User friendly dashboard that shows, Reservation of Books, Reservation of Discussion Room, LMS, and is easy-to-understand.
- Includes a log out button for easy log out.
  
The following are features for the admins:
- User friendly dashboard the contains request of reservation for books & rooms, Easy accept and reject of request, and one tap export to excel for easy data.
